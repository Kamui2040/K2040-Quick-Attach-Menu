# Weapon Menu Profiles

Weapon menu profiles let a configured Builder menu be shared without creating
an ESP or changing attachment data. A profile contains only one weapon's menu
source override, bracketed-text override, visibility, ordering, and custom
labels. General appearance, keybindings, inventory, installed attachments, and
mutation permissions are never exported.

## Export and import

Use **Export menu** in the Builder to create a `.k2040qam.json` file under:

`Data/F4SE/Plugins/K2040_Quick_Attach_Menu/Exports/`

Local exports immediately appear in the Builder's **Import menu** list. Profiles
installed by another mod are read from:

`Data/F4SE/Plugins/K2040_Quick_Attach_Menu/WeaponMenus/`

Importing replaces only the equipped weapon's Builder configuration. The import
is first written through the same atomic user-settings path as normal Builder
changes. If validation or saving fails, the previous configuration remains in
place.

## Weapon matching

Profiles identify their target by the source plugin filename plus the weapon's
local FormID. Display names, EditorIDs, and load-order-dependent full FormIDs are
not used for matching.

Before a profile is offered for import, the plugin requires:

- the exact target weapon identity to resolve to a loaded weapon;
- every referenced category and OMOD identity to resolve to its expected form
  type;
- the profile schema, labels, and identity lists to be valid and unambiguous;
- the equipped weapon to have the same stable identity.

A profile made for a similarly named weapon, a different plugin, or a different
local FormID is never offered. Imported presentation data cannot add attachment
options or bypass live attachment, inventory, dependency, or mutation checks.

## Nexus package layout

Copy the exported profile into this package structure before creating an
archive:

```text
Data/
  F4SE/
    Plugins/
      K2040_Quick_Attach_Menu/
        WeaponMenus/
          MyWeaponMenu.k2040qam.json
```

More than one profile may be installed for the same weapon. The Builder lists
each matching file and the user chooses which one to import. Importing copies
the selected configuration into the user's normal settings; removing the
profile package later does not silently change an already imported menu.

Profiles should be generated by the Builder. The format identifier is
`K2040QuickAttachWeaponMenu` and the current profile schema version is `1`.
